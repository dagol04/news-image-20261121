A one-day newspaper front page summing up Saturday, 21 November 2026: Russian missiles hit Poland, a magnitude 6.8 quake in Peru, US stocks sliding into correction, new UK–EU deals, Rikers Island to close by 2032, Denmark foiling an assassination plot, and KL Rahul completing the SENA set — plus a ticker of the day's other stories. A Node 22 program (stdlib only) draws the whole page with a fresh PNG encoder and bitmap font and writes it deterministically to `entry.png`.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
